# GazeNet V2 Results

This directory contains GazeNet V2 validation result figures.

Reported Epoch-2 validation results include:

- Mean angular error: 11.1583 degrees
- Median angular error: 9.3080 degrees
- Within 5 degrees: 18.56%
- Within 10 degrees: 54.19%
- Within 15 degrees: 75.64%

These are gaze angular-error evaluation metrics, not classification accuracy.
